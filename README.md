# FABRIC — Oliver Cassidy's Portfolio

A monochrome, editorial-magazine-style portfolio presented as a flipbook, with 3D page-turn navigation instead of scrolling.

## Technologies Used

- Next.js (App Router, Turbopack) - Framework
- React - UI
- Framer Motion - Page-turn animations and reveals
- TypeScript - Type safety

## Content

The site is a single flipbook with the following pages:

- Cover
- Editorial - a note from the desk
- Research - published papers
- Timeline - reverse chronology of work, research and education
- Projects - selected work
- Sport - track running and cycling
- Contact - directory of ways to reach me

Navigate with the on-page arrows, the page-tick bar, or the keyboard (←/→, Page Up/Page Down).

## Running Locally

1. Clone the repository

```bash
git clone https://github.com/ollycassidy13/Olly-Cassidy
cd Olly-Cassidy
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

## Deployment

The website is hosted on Vercel and can be accessed at: [https://olly-cassidy.vercel.app/](https://olly-cassidy.vercel.app/)
